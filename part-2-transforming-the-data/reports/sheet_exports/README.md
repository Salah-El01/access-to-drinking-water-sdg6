# Sheet Exports — Part 2: Transforming the Data

This folder contains PDF exports of the main Google Sheets analysis tabs used in **Part 2 — Transforming the Data** of the **Access to Drinking Water (SDG 6)** project.

These exports preserve the final spreadsheet outputs behind the analysis, including transformed data, derived variables, summary tables, validation checks, regional aggregations, and visual outputs.

The exports are included as supporting evidence for the spreadsheet-based workflow.

---

## Files Included

### Estimates of the use of water (2000-2020).pdf

Export of the transformed dataset sheet.

This file documents the row-level transformation layer used in Part 2. It contains the original drinking-water access variables and the derived fields created to support time-based progress analysis.

Main contents include:

- country or area name
- regional classification
- observation year
- national population estimate
- national, rural, and urban water-access variables
- year-difference calculation
- national Annual Rate of Change (`ARC_n`)
- rural Annual Rate of Change (`ARC_r`)
- urban Annual Rate of Change (`ARC_u`)
- rounded basic-access indicators
- full-access classification fields
- rural–urban ARC difference (`ARC_diff`)

This export shows the calculation layer behind the Part 2 analysis.

---

### Summary.pdf

Export of the summary and analytical dashboard sheet.

This file documents the main analytical outputs produced from the transformed dataset.

Main contents include:

- year representation analysis
- year-difference summary statistics
- Annual Rate of Change summary statistics
- access-by-area progress classification
- counts of missing, full-access, zero, positive, and negative ARC values
- rural–urban ARC comparison
- regional aggregation table
- year histogram
- regional ARC charts
- population and ARC comparison visual

This export shows the interpretation layer behind the Part 2 analysis.

## Analytical Role of These Exports

The sheet exports are included to make the spreadsheet workflow transparent.

They show how the project moves from source data to transformed data, then from derived ARC indicators to regional summaries and visual interpretation.

The exports are not meant to replace the written analytical report. Instead, they support it by documenting the final spreadsheet outputs used to generate the project findings.
