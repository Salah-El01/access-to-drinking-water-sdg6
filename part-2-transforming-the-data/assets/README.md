# Assets (Figures)

This folder contains the key exported figures and table extracts used in **Part 2 — Transforming the Data** of the **Access to Drinking Water (SDG 6)** project.

These visuals support the transformation-focused analysis based on the **WHO/UNICEF JMP drinking-water access estimates (2000–2020)**. They document how the dataset was explored, transformed, enriched with regional information, and analyzed through Annual Rates of Change (ARC).

The figures and table extracts help summarize the main patterns in basic drinking-water access progress across years, areas, and regions.

## Notes

- These figures were created from the Google Sheets working file used for data transformation, feature engineering, ARC calculations, regional enrichment, summary tables, and visual analysis.
- The chart visuals summarize the main analytical patterns, while the regional table extracts provide country-level evidence behind the regional comparisons.
- They are included here as exported visuals for documentation and reporting purposes.
- The spreadsheet remains the source of truth for the formulas, transformations, lookup logic, and calculations behind these figures.
- The original PNG files are stored in this folder. Some visuals are also linked through GitHub-hosted attachments in the README to ensure they display correctly in the browser.
